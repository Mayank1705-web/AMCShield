# Bug: [Name]

> Copy this template to a new file named `BUG-[short-name].md` for each
> meaningful bug. Do not accumulate multiple unrelated bugs in one file.

## Problem
What is broken?

## Discovery
How was the problem found? (e.g., which TEST_CHECKLIST.md step failed, or
what unexpected output was observed)

## Expected Behavior
What should happen?

## Actual Behavior
What currently happens?

## Root Cause
Why does it happen?

## Investigation
What was inspected? (files, logs, intermediate outputs)

## Attempts
What approaches were tried?

## Failed Attempts
What did not work and why?

## Fix
What changed? (list files and the nature of the change)

## Verification
How was it tested? Reference the specific TEST_CHECKLIST.md command(s) run
and their actual PASS/FAIL result.

## Regression Protection
What prevents this from happening again?

## AI Model
Which AI/version worked on it?
